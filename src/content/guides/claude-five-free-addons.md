קלוד בלי תוספות הוא עוזר כללי. עם תוספות הוא מקבל תפקידים: איש שיווק, עורך מסמכים, מועצת יועצים, חוקר ומנהל משימות. אלה חמש התוספות מהסרטון, בסדר ההתקנה המומלץ, כל אחת עם הוראות צעד אחרי צעד.

**מה צריך:** חשבון קלוד (claude.ai). חלק מהתוספות עובדות בכל חשבון, ותוספת אחת (מחקר) עובדת הכי טוב בגרסה שמריצה כמה סוכנים במקביל, כלומר בחשבון בתשלום או בקלוד קוד. בכל מקרה ההתקנה עצמה חינמית.

## מה זה "תוספת" ואיך מתקינים אחת

תוספת (סקיל) היא תיקייה קטנה עם קובץ הוראות אחד, `SKILL.md`. קלוד קורא אותה כשהבקשה שלכם מתאימה לה, ופועל לפי ההוראות שבה. אין כאן תוכנה להתקין על המחשב.

1. מורידים את התוספת כקובץ ZIP (הקישור בכל סעיף למטה)
2. בקלוד נכנסים להגדרות, לאזור התוספות (Skills / Capabilities), ולוחצים על העלאת תוספת
3. בוחרים את קובץ ה-ZIP ומאשרים. התוספת מופיעה ברשימה עם מתג הפעלה
4. כותבים לקלוד בקשה שמתאימה לתוספת, והוא משתמש בה לבד

> מה זה לא עושה: תוספת לא הופכת את קלוד לחכם יותר, היא נותנת לו הוראות עבודה טובות יותר. התוצאה עדיין צריכה בדיקה שלכם לפני שהיא יוצאת ללקוח.

## כלל בטיחות לפני שמתקינים

תוספת היא הוראות שקלוד מבצע בפועל. אם קלוד מחובר למייל או לקבצים שלכם, תוספת לא טובה יכולה לגרום נזק. לכן:

1. מתקינים רק ממקורות מוכרים, כאלה שהרבה אנשים כבר הורידו
2. לפני הפעלה ראשונה מבקשים מקלוד לבדוק אותה

```prompt
קרא את הקובץ SKILL.md של התוספת שהעליתי. תגיד לי במשפטים פשוטים מה היא עושה, ואם יש בה משהו חריג: הוראה לשלוח מידע החוצה, למחוק קבצים או לגשת למשהו שלא קשור למטרה שלה.
```

## 1. ספריית שיווק: כ-40 כישורים שעובדים יחד

ספרייה חינמית של תוספות שיווק (מודעות, מסרים, דפי נחיתה, ניתוח מתחרים ועוד). אחרי ההתקנה קלוד כותב לכם מודעות ומסרים בצורה שיטתית, במקום להתחיל מאפס בכל שיחה.

1. נכנסים לדף הספרייה בגיטהאב: [github.com/coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)
2. לוחצים על הכפתור הירוק Code ואז Download ZIP
3. פותחים את הקובץ שהורד. בתיקייה `skills` יש תיקייה לכל כישור (למשל `copywriting`, `ad-creative`)
4. מכווצים ל-ZIP **רק את התיקיות שצריך**, תיקייה אחת בכל ZIP, ומעלים כל אחת בנפרד לקלוד (ראו "איך מתקינים אחת" למעלה). מתחילים בשלוש: `product-marketing`, `copywriting`, `ad-creative`
5. מתחילים תמיד מ-`product-marketing`: זה כישור הבסיס שכל האחרים קוראים קודם, והוא שואל אתכם על העסק והלקוחות

אם אתם עובדים בקלוד קוד, יש דרך קצרה יותר, שני משפטים בטרמינל: `/plugin marketplace add coreyhaines31/marketingskills` ואז `/plugin install marketing-skills`.

```prompt
כתוב לי שלוש מודעות לפייסבוק לשירות [השירות שלכם], ללקוחות ב[העיר או התחום]. לכל מודעה כותרת, טקסט קצר ופנייה לפעולה. כל מודעה בזווית שונה.
```

## 2. מסמכים בעברית: מיושרים לימין וכתובים כמו אדם

הבעיה: הצעת מחיר בעברית שיוצאת מיושרת לשמאל, עם נקודות ופסיקים במקום הלא נכון, ובניסוח שנשמע כאילו מכונה כתבה. תוספת טובה לתחום הזה מגדירה מראש יישור לימין וסגנון כתיבה אנושי.

הקבצים המוכנים של תכל'ס לסעיף הזה עדיין לא מצורפים למדריך. עד שיתווספו, אפשר לקבל את אותה תוצאה בלי הורדה, בשלושה צעדים:

1. פותחים שיחה חדשה בקלוד ומדביקים את הפרומפט שלמטה
2. מדביקים אחריו טקסט אחד שכתבתם בעבר (מכתב או הצעת מחיר), כדוגמה לסגנון שלכם
3. מבקשים מקלוד לשמור את ההוראות בפרויקט, כדי שיחולו על כל מסמך עתידי

```prompt
מעכשיו כל מסמך בעברית שאתה כותב לי: מיושר לימין, בלי כותרות באנגלית, סימני פיסוק במקום הנכון, משפטים קצרים וטבעיים כמו שאדם מדבר, בלי "בעולם המהיר של היום" ובלי ביטויים של שיווק מנופח. לפני הסיום קרא את המסמך שוב ותקן כל משפט שנשמע כמו תרגום. אם חסר פרט (מחיר, תאריך, שם), כתוב [להשלים] ואל תמציא.
```

## 3. מועצת היועצים: אמת במקום "רעיון מצוין"

קלוד נוטה להסכים איתכם. מועצת יועצים הופכת את זה: חמישה יועצים שונים בוחנים את ההחלטה, כל אחד מזווית אחרת (כספים, שיווק, לקוחות, תפעול, סיכונים), ויושב ראש מסכם לכיוון אחד ברור.

הקובץ המוכן של תכל'ס לסעיף הזה עדיין לא מצורף למדריך. אפשר להפעיל את אותה שיטה כבר עכשיו בפרומפט אחד, בלי התקנה:

1. פותחים שיחה חדשה
2. מדביקים את הפרומפט ומחליפים את ההחלטה שבסוגריים
3. קוראים קודם את ההתנגדויות, ורק אז את ההמלצה של היושב ראש

```prompt
אני שוקל החלטה: [תארו את ההחלטה במשפט או שניים, כולל מחיר או תקציב].
הפעל מועצה של חמישה יועצים: איש כספים, איש שיווק, נציג הלקוח, איש תפעול ובודק סיכונים. כל יועץ כותב בנפרד, בלי לרכך ובלי לאזן, ומחזק את הזווית שלו עד הסוף. אחר כך כל יועץ מבקר את שני היועצים האחרים. בסוף יושב ראש כותב המלצה אחת ברורה, כולל "לא" אם זו התשובה, ושלושה צעדים ראשונים. אל תחמיא לי.
```

## 4. מחקר: כמה סוכנים בודקים במקביל

במקום שקלוד יחפש תשובה אחת, התוספת גורמת לו לשלוח כמה סוכנים במקביל: אחד על מתחרים, אחד על מחירים, אחד על לקוחות. הם חוזרים אליו, והוא מחבר דוח מסודר אחד.

המחקר הוא התוספת היחידה בחמישייה שהספרייה המוכנה שלה מכוונת לאנשים טכניים, אז כאן יש שתי דרכים:

1. **דרך מהירה לכולם:** מדביקים את הפרומפט שבסוף הסעיף ומבקשים מקלוד לחלק את העבודה לשלושה חלקים. בקלוד קוד או בחשבון שמריץ סוכנים, הוא יריץ אותם במקביל. זה מספיק למחקר עסקי רגיל
2. **למי שרוצה את הספרייה המלאה:** [github.com/orchestra-research/AI-research-SKILLs](https://github.com/orchestra-research/AI-research-SKILLs), Code ואז Download ZIP (כ-19MB). כל כישור יושב בתיקייה משלו, ומעלים לקלוד תיקייה אחת בכל פעם כמו בהוראות "איך מתקינים אחת"

> מה זה לא עושה: הספרייה הזאת (כ-100 כישורים) נכתבה לחוקרי בינה מלאכותית וללמידת מכונה, לא לבעלי עסקים, ורוב הכישורים בה לא רלוונטיים לכם. אם אתם לא טכניים, דרך 1 היא הנכונה.

```prompt
בדוק עבורי את השוק של [השירות שלכם] ב[העיר או הארץ]. תחלק את העבודה לשלושה חלקים: מתחרים (מי הם, מה הם מציעים), מחירים (טווחים וכל מה שכלול), לקוחות (מה הם מבקרים ומה מפריע להם). בסוף דוח אחד: ממצאים, מה אפשר לעשות מחר בבוקר, ומה לא הצלחת לאמת. ליד כל נתון כתוב מאיפה הוא.
```

## 5. ניהול משימות: קלוד שזוכר ומתכנן את היום

התוספת האחרונה היא זו שחוסכת הכי הרבה זמן: קלוד זוכר מה סגרתם, מתכנן לכם את היום ולא שוכח אף לקוח. זו חבילה (Plugin) שמכילה כמה כישורים, והיא מותקנת ישירות מהספרייה של קלוד.

1. בקלוד פותחים את ספריית התוספות (Directory / Plugins)
2. מחפשים Productivity
3. בוחרים את החבילה הרשמית ולוחצים על התקנה
4. מתחילים בבוקר עם הפרומפט שלמטה ומסיימים בו את היום

```prompt
אלה המשימות שלי להיום: [רשימה]. אלה הלקוחות שמחכים לתשובה ממני: [שמות]. תמיין לפי דחיפות, תציע סדר עבודה ללוח זמנים של [שעות], ותזכיר לי מה סגרתי אתמול ומה נשאר פתוח. בסוף היום אעדכן אותך ואתה תכין את המחר.
```

## הצעד הבונוס: לבקש מקלוד להמליץ לכם

אחרי שהתקנתם את החמש, קלוד כבר מכיר את סוג העבודה שלכם. כתבו לו:

```prompt
על בסיס כל מה שאתה מכיר אותי, תמליץ לי על התוספות הכי טובות שייקחו את העבודה שלי איתך שלב אחד קדימה.
```

## בדיקה מהירה אחרי ההתקנה

1. התוספת מופיעה ברשימה ומתג ההפעלה דלוק
2. מבקשים משהו שמתאים לה, ורואים שהתשובה מתאימה לתפקיד (למשל מודעות בשלוש זוויות)
3. אם התשובה נראית כמו תשובה רגילה, כותבים לקלוד במפורש "השתמש בתוספת [שם]"
